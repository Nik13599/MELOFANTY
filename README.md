# MELOFANTY — интерактивная демонстрация

Демо-сайт музыкальной шоу-игры «МЕЛОФАНТЫ». Визуальный стиль основан на материалах @melofanty.by.

## Ссылки

- [Публичный предпросмотр](https://melofanty-preview.kolyaselekh.workers.dev/)
- [Полноэкранный игровой симулятор](https://melofanty-preview.kolyaselekh.workers.dev/melofanty_screen_game.html)
- [Instagram организатора](https://www.instagram.com/melofanty.by/)

## Работа с файлами

- `index.html` — адаптивная главная страница с афишами и интерактивным предпросмотром.
- `melofanty_screen_game.html` — игровой симулятор с командами, числами, выбором песни и привязанным к ней фантом, ставками, тремя турами и финалом.

Обе HTML-страницы содержат встроенные стили, скрипты и изображения для автономной демонстрации. Часть фоновых фото и веб-шрифтов загружается из внешних сервисов при наличии интернета.

## Публикация

Отдельный Cloudflare Worker `melofanty-preview` раздаёт HTML из **публичной ветки `main` этого репозитория**. Обновления в GitHub появляются на публичном адресе после истечения краткого кеша (порядка двух минут). Если изменится название HTML-файлов, понадобится обновить маршрут Worker.

## Ограничения демонстрации

Игровые треки, фанты и очки условные и используются для объяснения механики; реальные музыка, синхронизация разных устройств, база участников, обработка заявок и приём оплаты не подключены. Для реальной регистрации используется Instagram организатора. Архивные даты мероприятий не означают доступные сейчас билеты.
